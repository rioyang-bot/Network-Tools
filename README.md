# 網路工具 Network Tools

單一執行檔 `NetworkTools.exe`，不需安裝任何東西 (使用 Windows 內建 .NET Framework 4.x)。
開啟時自動以系統管理員執行（會出現 UAC 確認視窗）。分頁可用 Ctrl+Tab 切換。

## 第一分頁：網卡 IP 設定
- 自動偵測所有網卡（未連線的網卡會顯示已儲存的設定）；滑鼠停在網卡上可看完整描述
- **★ 設為預設網卡**：預設網卡永遠排在最上面並自動選取
- **隱藏 / 取消隱藏**：不常用的網卡可隱藏；打開「顯示已隱藏」可再顯示
- 輸入 `IP/遮罩`，例如：
  - `192.168.100.100/24` → Gateway 自動帶入 `192.168.100.254`
  - `192.168.100.54/26` → Gateway 自動帶入 `192.168.100.62`
  - 也可輸入 `192.168.100.100 255.255.255.0`；只輸入 IP 時預設 /24
  - Gateway 可手動修改，留空表示不設定 Gateway
- **套用 (設為主要 IP)**：取代該網卡所有 IP
- **新增為額外 IP**：保留原 IP，再加第二、三組 IP（同 Windows 進階 TCP/IP 設定）
- 點「目前設定」中的 IP 可帶入編輯；可刪除選取的 IP、或改回 DHCP

### 設定檔
- 「變更 IP」右上角 **設定檔 ▼**
  - **將目前欄位存成設定檔…**：把 IP / Gateway / DNS 存成一個有名字的設定檔
  - 點選設定檔：帶入欄位，並詢問是否立即套用到目前選取的網卡
  - **刪除設定檔**

### 一鍵還原
- 本程式第一次變更某張網卡時（套用、新增、刪除 IP、改 DHCP），會先記錄它原本的設定
- 「目前設定」右上角 **↶ 還原**：改回記錄的原始設定（DHCP 或原本的固定 IP / Gateway / DNS），還原後清除紀錄
- 沒有紀錄時按鈕為灰色

## 第二分頁：網段掃描
- 輸入 `192.168.1.0/24`、`192.168.1.10-50` 或 `192.168.1.10-192.168.2.20`（最多 4096 個位址），按 **開始掃描**
- 右側 ▾ 可直接選擇電腦各網卡所在的網段
- 結果顯示 IP、延遲、TTL、MAC、廠牌、主機名稱；本機會標示「本機」
- **ARP 偵測**：對不回應 Ping 的位址再送 ARP，可找到關閉 Ping 的設備（限電腦所在網段，標示「僅 ARP 回應」）
- 雙擊結果 → 切到 Ping 分頁並開始 Ping；右鍵 → PuTTY 連線、開啟網頁 (http / https)、複製 IP / MAC / 整列
- **廠牌**：內建常見設備廠牌；按 **下載廠牌資料庫** 從 Wireshark 官方網站下載完整清單（約 3 MB，存成程式資料夾內的 `manuf`），之後大部分設備都能顯示廠牌。也可自行把 IEEE 的 `oui.txt` 放在程式資料夾。

## 第三分頁：Ping / PuTTY
- 輸入 IP，按 **Ping**（或按 Enter）開始；再按一次停止。可切換是否持續 Ping
- Ping 通時狀態列顯示綠色
- 按 **PuTTY 連線**：自動停止 Ping，並用 PuTTY 連線到目前輸入的 IP
  - 可選 SSH / Telnet、埠號、使用者名稱
- **Serial (Console 線)**：協定選 Serial，選 COM 埠（▾ 會列出電腦上的 COM 埠與裝置名稱）與鮑率，按 **PuTTY 連線** 開啟序列埠連線（8N1、無流量控制）
- 自動尋找 putty.exe（程式同資料夾、PATH、Program Files）；找不到時可用「PuTTY 路徑…」指定

## 設定儲存
視窗大小固定為 1080 × 960 像素（不可調整、不可最大化）。
視窗位置、預設與隱藏的網卡、設定檔、還原紀錄、IP / Ping / 掃描歷史紀錄等，
自動存在 exe 旁的 `NetworkTools.ini`（若該資料夾無法寫入則存在 `%APPDATA%\NetworkTools\`）。

## 重新編譯
修改 `src\` 內的原始碼後，執行 `build.bat` 即可產生新的 `NetworkTools.exe`。
若不想每次開啟都出現 UAC 視窗，將 `src\app.manifest` 中的 `requireAdministrator` 改為 `asInvoker` 後重新編譯（變更 IP 時程式會再詢問是否以系統管理員重新啟動）。
